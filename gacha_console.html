先过这道判定，再谈抽卡

抽卡只对随机型失败有效。对结构型失败（状态不守恒 / 接触物理 / 多步因果），每次都会在同一处、以同一方式复现 —— 抽 N 次只是花 N 倍算力拿到 N 份同样错的片子。没有这道判定，抽卡没有地板。

两个硬性提醒

① 重抽必须换新 seed。同 prompt + 同 seed + 同输入 = 输出逐位相同（已实测：音轨 PCM 一致）。照字面重提同一任务，只会花 N 倍算力拿到 N 份视觉相同的片子和 N 次相同的否决。

② 判官必须输出「失败类型」，不只是「通过 / 不通过」。判官看不到「这是第几次抽」，它天然会建议重抽 —— 但对结构型失败，重抽 N 次仍然不行。

模型边界

单次耗时按实测线性外推：t ≈ 20L + 43（实测锚点 2s→83s、3s→102s、4.5s→132s）。L≥7.5s 属外推区，有非线性开销，别当基准用。15s 段等高收益方案需官方 API（本地 768p base 段长受限）。
