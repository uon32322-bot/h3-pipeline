## 二、文案三分流（schema `adapter_rules.4`）

| 通道 | 内容 | 去向 | 为什么 |
|---|---|---|---|
| **① onscreen_en** | `CUSHION RUNNER` / `HIGH-REBOUND FOAM` / `BREATHABLE` / `JACQUARD MESH` / `ON FOOT` / `LINK BELOW` | **后期 PIL 叠加**（本次未交给 H3 画） | 英文卖点词必须 100% 清晰可读；H3 原生文字渲染**未验证**，风险不可接受 |
| **② voiceover_zh** | 6 句中文旁白，总占 14.85 s | **macOS `say`（Tingting）+ ffmpeg 混音** | 零 GPU 依赖、零成本、可逐句改；不占用 3090 |
| **③ post_zh** | 卖点副条 / `￥129 起` / 尺码 / CTA / `AIGC 生成` 标识 | **后期 PIL 叠加** | 价格·CTA·合规标识属"绝不让模型画"的一类 |

> ⚠️ **本次对 schema 的一处有意偏离**：schema 的 `onscreen_en` 原设计是"逐字写进 H3 prompt"。
> 本次改为**全部后期叠加**，理由是 H3 是"忠实插值器"（插图层的忠实继承者），
> 画面内文字只可能来自首尾帧而非提示词，而提示词画字在本项目**尚无实测证据**。
> ⇒ 已登记为待验证项 **V1**（见 REPORT25 §六）。

## 三、闸门② 审核记录（生成前硬约束）

| 判据 | 本分镜逐镜核对 | 结论 |
|---|---|---|
| 动作白名单（9 项） | 镜1 推近｜镜2 推近｜镜3 静置｜镜4 特写平移｜镜5 推近｜镜6 推近 | ✅ 全在名单内 |
| **每镜主体动作数 = 1** | 逐镜：全为 1 个运镜；"光影流动"记为**光效**非主体动作（镜2/镜4） | ✅ |
| 禁写·物理不可生成 | 无涂开/倒出/拧开/涂抹/挤压（本品类天然不涉及） | ✅ |
| 禁写·可生成性四类 | 无双主体精确交互／无内部心理／无一拍三步动作链／**保留"no walking, no waving"防乱动保险句** | ⚠️ 见下 |
| 否决·可验证物理结果 | 无 | ✅ |
| 时长贴 17k+5 网格 | 每段 5.0 s → `snap_frames` = **124 帧**（17×7+5） | ✅ |
| 锚定照＝独立照片，禁网格 | 首尾帧均为**单张独立图**（几何派生自同一张源图，非拼贴） | ✅ |
| 提示词禁用颜色词 | 已移除旧 `warm light sweep`（**变色根因**），改 `a soft neutral light sweep`；仅保留与实物一致的 `black and white / silver / light blue` 描述 | ✅ |
| 画面内文字不交模型 | 全部后期叠加 | ✅ |

> ⚠️ **"否定式动作"的有意保留**：闸门②把「否定式动作」列为禁写，但镜5 保留
> `no walking, no waving, no turning`。理由：这是**防乱动保险句**（约束人物不要自行走动），
> 不是"要求模型执行一个否定动作"（如"不要走过去"）。REPORT24 已实测该写法下模特五帧姿势完全一致 ⇒ **判据需要按语义细分**，已登记为建议修订 **V2**。
