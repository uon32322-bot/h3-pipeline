# 产品文字信息标准格式 (轻量模板)

> 目标: 用最少的字数, 让 LLM 准确识别产品特征, 生成符合 6 宫格视频生成规范的描述。

## 📋 模板 (用户填写示例)

```
【产品名称】净澈·氨基酸温和洁面乳
【所属品类】美妆个护_面部清洁
【产品形态】翻盖塑料软管, 白色管身
【核心卖点】
1. 氨基酸表活体系, 弱酸亲肤
2. 绵密泡沫深入毛孔
3. 无皂基无酒精, 敏感肌可用
【使用场景】早晚洁面, 通勤/居家
【适用人群】敏感肌/干皮/混油皮
【拍摄参考】洗手间镜子前, 米色台面, 自然光
【禁止项】不要模特手持展示以外姿势, 不要拆包装
```

## 🎯 字段说明 (按重要性排序)

| 字段 | 必填 | 格式 | 示例 |
|---|---|---|---|
| **产品名称** | ✅ | 品牌+系列+产品名 | 净澈·氨基酸温和洁面乳 |
| **所属品类** | ✅ | 大类_细分 | 美妆个护_面部清洁 |
| **产品形态** | ✅ | 形态描述 | 翻盖塑料软管/金色方管/矮胖圆瓶 |
| **核心卖点** | ✅ | 1-3 条短句 | 氨基酸亲肤 / 绵密泡沫 / 敏感肌可用 |
| **使用场景** | 选 | 1-2 个 | 早晚洁面 / 通勤妆前 |
| **适用人群** | 选 | 1 类 | 敏感肌 / 油皮 / 学生党 |
| **拍摄参考** | 选 | 简述 | 洗手间镜子前+米色台面+自然光 |
| **禁止项** | 选 | 不要... | 不要模特/不要拆包装/不要背景文字 |

## 📐 格式约束

- **每行不超过 25 字**
- **卖点 ≤3 条** (超过 3 条会稀释核心)
- **拍摄参考 ≤30 字** (越具体越好, 描述场景+光线+色调)
- **禁止项 ≤3 条** (用"不要/不许/禁止"开头的简短描述)

## 🎬 6 宫格生成规则 (隐含)

LLM 在生成宫格图 prompt 时, 会**自动按以下规则**:

1. **6 个独立 cell, 3 行 2 列, 无嵌套**
2. **产品形态/颜色/位置 6 镜一致**
3. **真实摄影风格, 非海报/3D/插画**
4. **无文字、无图标、无水印、无价格**
5. **每镜动作 ≤1.3s, 6 镜总 ≤8s**
6. **按品类自动选核心动作** (涂抹类=膏体贴+涂抹 / 穿戴类=穿戴+展示)

## ✅ 用户填写检查清单

填好后, **按这个清单自查**:

- [ ] 产品名称**有品牌** (用户不能填"洁面乳")
- [ ] 品类**带细分** (不能填"化妆品")
- [ ] 产品形态**带包装描述** (不能只填"塑料瓶")
- [ ] 卖点**≤3 条**, 每条**≤15 字**
- [ ] **至少 1 个**场景或人群信息
- [ ] 拍摄参考**有具体地点+光线** (不能只填"好看")
- [ ] 禁止项**用"不要/禁止/不许"** 开头

## 🎯 示例对照表

### ✅ 标准填写
```
【产品名称】净澈·氨基酸温和洁面乳
【所属品类】美妆个护_面部清洁
【产品形态】翻盖塑料软管, 白色管身, 银色翻盖
【核心卖点】氨基酸亲肤 / 绵密泡沫 / 敏感肌可用
【使用场景】早晚洁面
【适用人群】敏感肌/干皮
【拍摄参考】洗手间镜子前, 米色台面, 自然侧光
【禁止项】不要模特正脸特写, 不要文字水印
```

### ❌ 不规范填写
```
【产品名称】洁面乳                    ❌ 无品牌
【所属品类】化妆品                     ❌ 无细分
【产品形态】塑料瓶                     ❌ 无细节
【核心卖点】好用、不刺激、保湿、美白、便宜    ❌ 5 条, 太长, 杜撰"美白"
【使用场景】家里                       ❌ 太模糊
【适用人群】所有人                     ❌ 不具体
【拍摄参考】好看                       ❌ 无意义
【禁止项】                            ❌ 缺失
```

## 💡 简化模板 (5 行核心版)

如果用户不想填这么多, **最少 5 行必填**:

```
【产品名称】品牌·产品全名
【所属品类】大类_细分 (如 数码_耳机)
【产品形态】包装类型+颜色
【核心卖点】卖点1 / 卖点2 / 卖点3
【拍摄参考】场景+光线 (如 客厅+暖光)
```

**其他字段 (使用场景/适用人群/禁止项) 全部可选**。

## 🔄 与 LLM 配合

LLM 拿到这个格式后, 会自动:
1. **识别产品**: 类别/卖点/使用场景
2. **生成文案**: 5 段式 (钩子+3卖点+场景+CTA)
3. **生成 6 镜分镜**: 按品类给动作建议 (涂抹/穿戴/食用等)
4. **生成宫格图 prompt**: 用本模板 (grid_prompt_v6.py) 的强约束

如果**用户填的信息完整 + LLM 选对了**, 宫格图 90%+ 概率无崩坏。
如果**用户填的信息模糊**, LLM 只能"猜", 宫格图就容易出文字/海报/嵌套子图。
