## 三、⭐ 生成分组表（S1.5 · v2.0 新增）

> **目的**：把相邻镜合并成「一条片内多镜」的生成段（≤ **362 帧 = 15.083 s**），**段长贴音轨句末**。

| 段 | 含镜 | 段起止 | 帧数 | 时长 | 音频模式 | 锚点（Picture） | 音轨区间 | 估算耗时 |
|---|---|---|---|---|---|---|---|---|
| **G1** | 镜 1–3 | 0.000 – | | | ☐锚定 ☐不锚 | 首帧 + 中间锚点 | | |
| **G2** | 镜 4–5 | – | | | | | | |
| **G3** | 镜 6 | – – 40.000 | | | | | | |
| | | | **合计** | **40.000 s** | | | | **≈ ____ min** |

### 分组三原则

| # | 原则 | 说明 |
|---|---|---|
| 1 | **段边界贴音轨句末** | 口播句在 6.85 s 结束 ⇒ 段切在 6.85 s 附近（不留半句话） |
| 2 | **段边界落在转场点** | 优先硬切/场景变更处，不切在动作中段 |
| 3 | **每段 2–4 镜** | 超 4 镜 ⇒ 单镜被压到 <2 s，动作做不完（H3 每段真实"在动"时间恒定 1.4–2.3 s） |

### 额外硬约束

- [ ] 每段 ≤ **362 帧**，且**段帧数必须 ≡ 5 (mod 17)**（合法值：22/39/56/73/90/107/124/141/158/175/192/209/226/243/260/277/294/311/328/345/362）
- [ ] **成片总长 = 各段之和，不必贴网格**（例：960 = 243+362+175+107+73，n=5 段）
- [ ] ⭐ **没有任何 `L` 镜跨段**（跨段 ⇒ 语音被两次独立重渲染 ⇒ 音色 + 口型双断）
- [ ] L 片：**整条音轨作单锚点挂段首**（不做多音频锚点叠加 —— 未验证）
- [ ] ⭐ **场景变更只发生在段边界**（段内换场景会让"片内多镜"变成跳变）

### 段数怎么定（先算可行性，别拍脑袋）

```
Σ(17k_i + 5) = 总帧数 T   ⇒   5n ≡ T (mod 17)   ⇒   n 被 T 唯一约束
40 s / 960 帧：5n ≡ 8 ⇒ n ≡ 5 (mod 17) ⇒ 只有 n=5（22/39… 不实用）
32 s / 768 帧：5n ≡ 3 ⇒ n ≡ 4 (mod 17) ⇒ n=4
50 s / 1200 帧：5n ≡ 10 ⇒ n ≡ 2 (mod 17) ⇒ n=2 不可行（每段 600 > 362）
                ⇒ 50 s 档让各段之和 ≥ 1200 并在装配时裁尾，或改总长到 1195（n=6）
```

### 成本标度（768×1344 / 8 步 / 3090 显存受限）

```
单段耗时 t(f) = 431 × (f/124)^1.6697 秒      两端实测精确拟合
实测锚点：124 帧 = 431.0 s (7.2 min)｜243 帧 = 1325.5 s (22.1 min)
```

| 帧 | 秒 | 单段 | 每 1 s 成片要多少 GPU |
|---|---|---|---|
| 73 | 3.04 | 3.0 min | 59 s |
| 107 | 4.46 | 5.6 min | 75 s |
| 124 | 5.17 | 7.2 min | 83 s |
| 175 | 7.29 | 12.8 min | 105 s |
| 243 | 10.13 | **22.1 min**（实测） | 134 s |
| 362 | 15.08 | 43.0 min（外推） | 177 s |

> **分段数不由成本决定**：允许逐段重抽时「段越短越省」，要求一次过时「段越少越省」—— **结论相反，所以按内容定**。
> 演示：同样 180 帧的 CTA 段，1 段 ≈ 13.6 min；拆成 107+73 两段 = 8.5 min ⇒ **拆开省 37%**（但多一个接缝）。
> 总量参考：32 s ≈ 60 min｜**40 s ≈ 86 min**｜50 s ≈ 115 min（可重抽口径，五段/六段方案）。
