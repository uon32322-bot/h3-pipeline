## 一、⭐ 概念先钉死（别搞错）

> **H3 在这一环是「音画同步器」，不是「配音员」。**
> 配音由 **外部 TTS** 出（音色可控）；H3 负责把它**同步进画面**。

| 机制 | H3 在干什么 | 实测 |
|---|---|---|
| FL2VA `AddGuide(audio)` | 把**已有语音同步进画面**（每步重新注入，音轨内容保留） | ✅ DTW 0.036 vs 他句 0.20 |
| Ref2VA `<d>[English]…</d>` | 自己念台词 | ✅ ASR 5/5 逐字准；但该链路**不锁身份**（已弃为生产主链路） |
| Ref2VA `ref_audios` | 名义上的音色条件 | ❌ **音轨逐位相同**（音色零效果），算力 +95~115% |

## 六、闸 C · 音频可行性自检

- [ ] 口播字数 ≤ **目标时长 × 5 字/秒**（超了 ⇒ 先删 ③ 的形容词，再删 ② 的修饰）
- [ ] 口播字数 ≥ 目标时长 × 4 字/秒（低于 ⇒ 说明内容太薄，补一个"事实"而非形容词）
- [ ] **整片音轨单源**（全片只用一条音轨；L 镜不额外贡献音轨）
- [ ] 标了 `L` 的镜**都有可辨识人脸且处于说话构图**
- [ ] 标了 `L` 的镜**都没有大幅手部/产品动作**（「说话时别做别的」）
- [ ] **没有任何 `L` 镜跨生成段**（跨段 ⇒ 口型与音轨双断）
- [ ] ⭐ **标 `V` 的镜里没有「脸可辨 + 说话构图」**（约束②，否则口型穿帮）
- [ ] L 镜的**音频锚点切片时长 = 该段段长**（帧数逐位一致）
- [ ] **中文口型已过标定**（r ≥ 0.30 且 |滞后| ≤ 2 帧）—— 未过则本片不标 L
- [ ] 音轨总长 = 成片总长；句间空隙 ≤ 0.3 s（L 片）/ ≤ 0.5 s（V 片）
- [ ] TTS 与 ASR 均**未占用 3090 的 CUDA**

## 六·五、A 段判官（S6 · 音轨判项，全程 CPU）

> 脚本：`~/.workbuddy/skills/h3-fl2va-video-pipeline/scripts/judge_audio.py`
> 纪律：**判定音轨一律用算术/信号处理，不问 VLM**；未标定项**只报数值**。

| 判项 | 方法 | 标定状态 | 阈值 |
|---|---|---|---|
| **A-01** 音轨非静音 | 能量 dB | ✅ 已标定 | 见脚本 `TH` |
| **A-02** 音轨 vs TTS 参考一致 | **log-mel + DTW**（对自持 TTS，零网络） | ✅ 已标定 | `max_dtw_ratio=0.75`、`max_dtw_abs=0.10` |
| **A-03** 口型同步 | 嘴区互相关 | ⚠️ **仅测量** | 仅 `--force-a03` 出结论 |
| **A-04** 语音在段内结束 | 对齐 `track_manifest.json` | ✅ 已标定 | 见脚本 `TH` |
| **A-05** 跨段音色一致 | 自相关 F0 中位数 | ⚠️ 待标定 | 只报数值 |

**用法速查**

```bash
# V 片：拿生成的段音轨 与本片 TTS 参考比对（A-02 主路径）
python3 judge_audio.py --mode V --seg xxx.mp4 \
  --ref-vo vo/track_full.wav --ref-other vo/other.wav \
  --manifest vo/track_manifest.json --seg-index 3 --out a3.json

# L 片要测口型（仅实验/标定）
python3 judge_audio.py --mode L --seg xxx.mp4 --face --force-a03
```

> ⚠️ **A-02 不用 ASR 的原因**：`faster-whisper` 权重下载被 HF CAS **401** 拦死（实测）。
> 但我们**本来就持有喂进去的那条 TTS** ⇒ 直接与它做 DTW 即可，零网络、约 1 s（REPORT3 同源方法）。
> 标定 4 点全过：同内容异音色 0.41 ✅｜异内容 2.17 ✅｜纯环境音 0.86 ✅｜真实 H3 输出 0.18 ✅。
