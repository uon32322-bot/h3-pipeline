# GEM3.7-flash vs TT5.6-luna 评测报告

## 评测背景

评测目标: 选定 GEM3.7-flash 和 TT5.6-luna 两个 LLM 作为 H3 带货视频主生产模型。

评测样本: 9 个产品 × 2 模型 = 18 套生成结果 (从 ~/Desktop/新测试 0921/测试结果/ 拉取)
评测维度: 文案 + 分镜脚本

## 评测方法

采用 skill `engineering/ecommerce-ai-video-pipeline` 下的 4 个核心 references:
1. `storyboard-script-quality.md` (分镜 4 类硬约束 + 6 增强点)
2. `copywriting-judge-optimization.md` (文案精选 3 卖点 + QA 自问自答)
3. `h3-prompt-8-dimensions-and-hallucination-defense.md` (8 维度模板 + 否定锚点)
4. `structure-fullness-and-hand-action-drift.md` (手部动作细化)

## 评测维度 (10 项)

### 文案 (4 项)

| 维度 | 标准 |
|---|---|
| 钩子 | 口语化+有钩子 (危言/反常识/提问), 禁用"大家好"开场 |
| 卖点 | 3 条具体画面化, 禁用空泛词 (顺/利落/显精神) |
| 结构 | 5 段式完整 (tagline/selling_points[3]/scene/cta) |
| 真实性 | 不杜撰数字, 无夸大功效 |

### 分镜 (6 项)

| 维度 | 标准 |
|---|---|
| 数量 | 必须 6 镜 |
| 时长 | 6 镜总和 ≤8s, 每镜 ≤1.3s |
| 动作细度 | 手部动作细到指节 (拇指/食指/掌心/虎口/手腕) |
| 品类适配 | 涂抹类中间 2 镜膏体贴+涂抹 |
| 结构 | 镜1镜6镜像, 中间是核心动作 |
| 可生成 | 无"随后/接着/然后"等时序跳变词 |

## 关键发现

### gem-3.7-flash 优势
1. **完整率高**: 9/9 个产品都生成了完整文案+6 镜分镜, 无 bug
2. **动作细化**: 主动细化到指节 (例: "右手食指与拇指捏住管身中段, 顺时针拧出膏体")
3. **行业垂直**: 能写出 "ANC降噪按键" "40mm CD纹" "蛋白皮记忆棉" 等专业描述
4. **时长严格**: 6 镜累加精确到 0.0-8.0s

### tt-5.6-luna 优势
1. **部分产品动作更生动**: 例: 02_口红的"膏体贴合下唇中心向右上唇角再向左上唇角"细节更细
2. **文案钩子更口语化**: "姐妹冲！" "地铁轰鸣一下没了" 比 gem 更亲切

### tt-5.6-luna 劣势 (致命)
1. **03_零食文案完全空**: 返回 {"_error"} 而非 fallback, 链路断裂
2. **09_耳机分镜退化为占位描述**: "镜1: 展示充电盒" / "镜2: 打开盒盖" — 没意义
3. **时长超 8s**: 03_零食总时长 18s (3 倍), 严重违规
4. **杜撰数字**: "白两度" 是模型自己编的, 违反真实原则

## 结论

**gem-3.7-flash 作为绝对主力** (跑全品类 9/9 都能保证基本质量)
**tt-5.6-luna 作为 VLM 备用** (仅用于图片理解, 文案/分镜仍由 gem-3.7-flash 主出)


### 已实施的硬约束 (来自 skill)

**文案 prompt 4 条** (copywriting-judge-optimization):
1. 钩子: 危言/反常识/提问, 禁用"大家好"
2. 3 卖点: 1 个具体画面 + 1 句购买理由
3. 不杜撰数字
4. ≤25字/段

**分镜 prompt 9 条** (storyboard-script-quality + h3-prompt-8-dimensions):
1. 时长严格 (≤8s 总, ≤1.3s 单镜)
2. 单镜动作唯一
3. 禁止时序跳变词
4. 手部动作细到指节
5. 物理形态先于颜色 + negation
6. 镜1镜6镜像
7. 中间 2 镜核心动作
8. 产品前 3 秒入画
9. 数量限定 only ONE product
